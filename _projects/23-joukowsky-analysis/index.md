## Key Features
- **Coordinate Generation:** MATLAB scripts to transform a cylinder into a Joukowsky airfoil.
- **CFD Simulation:** Flow analysis around the airfoil using Ansys Fluent.
- **Visualization:** Pathlines and pressure contours to visualize the flow field.

## Files
- **MATLAB Scripts:** Code for generating coordinates and performing preliminary analysis.
- **Ansys Project:** The simulation setup and results.
