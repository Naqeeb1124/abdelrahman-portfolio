## Overview
This project focuses on the design and analysis of a Ramjet engine. It involves calculating the flow properties at various stations of the engine and analyzing the thermodynamic cycle.

## Key Features
- **Cycle Analysis:** Computation of pressure, temperature, and Mach number at the diffuser, combustor, and nozzle.
- **Performance Metrics:** Calculation of thrust, specific impulse (Isp), and efficiency.
- **Visualization:** Generation of Temperature-Entropy (T-S) diagrams to visualize the engine cycle.

## Files
- **Report:** Detailed documentation of the design process and results.
- **MATLAB Scripts:** Code used for the numerical analysis and plotting.
