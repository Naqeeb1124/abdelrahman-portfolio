## Project Overview

This project focuses on the complete design and implementation of a robotic arm. It integrates mechanical design, electronic control, and software simulation.

## Key Features

- **Mechanical Design**: Custom parts designed in SolidWorks and prepared for manufacturing with DXF files.
- **Control System**: Arduino-based control logic for precise movement.
- **Simulation**: MATLAB script for visualization and control analysis (`visualization_and_control_script.m`).

## Resources

The project resources include the full engineering report, source code for both the microcontroller and simulation environment, and the CAD files used for fabrication.
