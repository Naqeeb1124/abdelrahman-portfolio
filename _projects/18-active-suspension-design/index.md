## Project Overview

This project involves the design and analysis of an active suspension system for a quarter car model. The goal is to improve ride comfort and handling by actively controlling the suspension forces.

## Key Features

- **Modeling**: Mathematical modeling of a quarter car suspension system.
- **Control Design**: Implementation of control algorithms to regulate the suspension.
- **Simulation**: Simulation of the system performance using MATLAB and Python.
- **Animation**: Visual animation of the suspension dynamics.

## Resources

The project includes a detailed report explaining the design process and results, as well as the source code in both MATLAB and Python. A video animation is also provided to visualize the system's behavior.
